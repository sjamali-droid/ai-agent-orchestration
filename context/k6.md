# Grafana k6 Documentation

Grafana k6 is an open-source, developer-friendly, and extensible load testing tool designed for testing the reliability and performance of applications and infrastructure. Built with a focus on minimal resource consumption, k6 enables engineering teams to run high-load performance tests including spike, stress, and soak tests while providing comprehensive metrics and analysis capabilities. Tests are written in JavaScript or TypeScript, making them accessible to developers and easy to integrate into existing codebases and CI/CD pipelines.

k6 serves multiple testing purposes including load and performance testing, browser-based performance testing through its browser module, synthetic monitoring for continuous availability validation, and chaos/resilience testing when combined with extensions like xk6-disruptor. The tool supports various protocols including HTTP/HTTPS, WebSockets, and gRPC, with extensibility through a robust extension ecosystem that allows adding support for new protocols or custom outputs.

## Basic Test Script Structure

Every k6 script requires a default exported function that contains the test logic. The script can include imports, options configuration, and lifecycle hooks.

```javascript
import http from 'k6/http';
import { sleep } from 'k6';

export const options = {
  iterations: 10,
};

// The default exported function is the entry point for the test
export default function () {
  http.get('https://quickpizza.grafana.com');
  sleep(1);
}
```

## http.get(url, [params])

Makes an HTTP GET request to the specified URL and returns a Response object containing the response body, headers, status code, and timing information.

```javascript
import http from 'k6/http';

export default function () {
  const res = http.get('https://test.k6.io');
  console.log(`Status: ${res.status}`);
  console.log(`Response time: ${res.timings.duration}ms`);
  console.log(JSON.stringify(res.headers));
}
```

## http.post(url, [body], [params])

Sends an HTTP POST request with an optional body. The body can be a string, object (for form data), or ArrayBuffer for binary data.

```javascript
import http from 'k6/http';

const url = 'https://quickpizza.grafana.com/api/json';

export default function () {
  // POST with JSON body
  let data = { name: 'Bert' };
  let res = http.post(url, JSON.stringify(data), {
    headers: { 'Content-Type': 'application/json' },
  });
  console.log(res.json().json.name); // Bert

  // POST with form data (automatically sets Content-Type: application/x-www-form-urlencoded)
  res = http.post(url, data);
  console.log(res.json().form.name); // Bert

  // POST with binary data
  const binaryData = new Uint8Array([104, 101, 108, 108, 111]);
  http.post(url, binaryData.buffer, { headers: { 'Content-Type': 'application/octet-stream' } });
}
```

## http.batch(requests)

Issues multiple HTTP requests in parallel over multiple TCP connections, simulating how browsers fetch resources. Returns an array or object of Response objects.

```javascript
import http from 'k6/http';
import { check } from 'k6';

export default function () {
  // Batch with array of arrays
  const responses = http.batch([
    ['GET', 'https://test.k6.io', null, { tags: { ctype: 'html' } }],
    ['GET', 'https://test.k6.io/style.css', null, { tags: { ctype: 'css' } }],
    ['GET', 'https://test.k6.io/images/logo.png', null, { tags: { ctype: 'images' } }],
  ]);
  check(responses[0], {
    'main page status was 200': (res) => res.status === 200,
  });

  // Batch with named requests
  const namedResponses = http.batch({
    'front page': 'https://k6.io',
    'features page': {
      method: 'GET',
      url: 'https://k6.io/features',
      params: { headers: { 'User-Agent': 'k6' } },
    },
  });
  check(namedResponses['front page'], {
    'front page status was 200': (res) => res.status === 200,
  });
}
```

## check(val, sets, [tags])

Validates boolean conditions against a value without aborting the test on failure. Returns true if all checks pass, false otherwise. Failed checks are tracked as metrics.

```javascript
import http from 'k6/http';
import { check, fail } from 'k6';

export default function () {
  const res = http.get('https://quickpizza.grafana.com/');

  // Single check
  check(res, {
    'response code was 200': (r) => r.status === 200,
  });

  // Multiple checks with custom tag
  const checkOutput = check(
    res,
    {
      'response code was 200': (res) => res.status == 200,
      'body size was larger than 123 bytes': (res) => res.body.length > 123,
    },
    { myTag: "I'm a tag" }
  );

  if (!checkOutput) {
    fail('unexpected response');
  }
}
```

## Thresholds

Thresholds define pass/fail criteria for test metrics. If conditions are not met, the test fails with a non-zero exit code, making them essential for CI/CD integration.

```javascript
import http from 'k6/http';
import { sleep } from 'k6';

export const options = {
  thresholds: {
    // HTTP errors should be less than 1%
    http_req_failed: ['rate<0.01'],
    // 95% of requests should be below 200ms
    http_req_duration: ['p(95)<200'],
    // 90% within 400ms, 95% within 800ms, 99.9% within 2s
    // http_req_duration: ['p(90) < 400', 'p(95) < 800', 'p(99.9) < 2000'],
  },
};

export default function () {
  http.get('https://quickpizza.grafana.com');
  sleep(1);
}
```

## Thresholds with Abort on Fail

Configure thresholds to abort the test immediately when crossed, preventing wasted resources on failing tests.

```javascript
import http from 'k6/http';

export const options = {
  vus: 30,
  duration: '2m',
  thresholds: {
    http_req_duration: [
      {
        threshold: 'p(99) < 10',
        abortOnFail: true,
        delayAbortEval: '10s', // Wait 10s before evaluating
      },
    ],
  },
};

export default function () {
  http.get('https://quickpizza.grafana.com');
}
```

## Thresholds with Tags

Apply thresholds to specific tagged requests for granular performance requirements on different endpoint types.

```javascript
import http from 'k6/http';
import { sleep } from 'k6';

export const options = {
  thresholds: {
    'http_req_duration{type:API}': ['p(95)<500'],
    'http_req_duration{type:staticContent}': ['p(95)<200'],
  },
};

export default function () {
  http.get('https://quickpizza.grafana.com/api/headers', {
    tags: { type: 'API' },
  });
  http.get('https://quickpizza.grafana.com/api/json', {
    tags: { type: 'API' },
  });

  http.batch([
    ['GET', 'https://quickpizza.grafana.com/favicon.ico', null, { tags: { type: 'staticContent' } }],
    ['GET', 'https://quickpizza.grafana.com/admin', null, { tags: { type: 'staticContent' } }],
  ]);

  sleep(1);
}
```

## sleep(t)

Suspends VU execution for the specified duration in seconds, simulating user think time between actions.

```javascript
import { sleep } from 'k6';
import http from 'k6/http';
import { randomIntBetween } from 'https://jslib.k6.io/k6-utils/1.2.0/index.js';

export default function () {
  http.get('https://k6.io');

  // Fixed sleep
  sleep(1);

  // Random sleep between 0-30 seconds
  sleep(Math.random() * 30);

  // Random sleep between 20-30 seconds using k6-utils
  sleep(randomIntBetween(20, 30));

  http.get('https://k6.io/features');
}
```

## group(name, fn)

Organizes test code into logical groups for better result organization and analysis. Groups can have their own thresholds.

```javascript
import { group } from 'k6';
import http from 'k6/http';

export const options = {
  thresholds: {
    'group_duration{group:::individualRequests}': ['avg < 400'],
    'group_duration{group:::batchRequests}': ['avg < 200'],
  },
  vus: 1,
  duration: '10s',
};

export default function () {
  group('visit product listing page', function () {
    http.get('https://quickpizza.grafana.com/api/json?letter=a');
  });

  group('add several products to cart', function () {
    http.get('https://quickpizza.grafana.com/api/json?letter=b');
  });

  group('checkout process', function () {
    http.batch([
      ['GET', 'https://quickpizza.grafana.com/api/json?letter=a'],
      ['GET', 'https://quickpizza.grafana.com/api/json?letter=b'],
    ]);
  });
}
```

## Scenarios

Scenarios configure VU and iteration scheduling with granular control, enabling multiple workloads to run in parallel or sequence with different executors.

```javascript
import http from 'k6/http';

export const options = {
  scenarios: {
    // Shared iterations: 10 VUs share 100 iterations
    shared_iter_scenario: {
      executor: 'shared-iterations',
      vus: 10,
      iterations: 100,
      startTime: '0s',
    },
    // Per-VU iterations: Each of 10 VUs runs 10 iterations
    per_vu_scenario: {
      executor: 'per-vu-iterations',
      vus: 10,
      iterations: 10,
      startTime: '10s',
    },
    // Constant arrival rate: 30 iterations per second
    constant_request_rate: {
      executor: 'constant-arrival-rate',
      rate: 30,
      timeUnit: '1s',
      duration: '1m',
      preAllocatedVUs: 50,
      startTime: '30s',
    },
  },
};

export default function () {
  http.get('https://test.k6.io/');
}
```

## Stages (Ramping VUs)

Define load patterns with ramping VUs for average-load, stress, or soak testing by specifying target VU counts over time periods.

```javascript
import http from 'k6/http';
import { sleep } from 'k6';

export const options = {
  stages: [
    { duration: '5m', target: 100 },  // Ramp up from 0 to 100 users over 5 minutes
    { duration: '30m', target: 100 }, // Stay at 100 users for 30 minutes
    { duration: '5m', target: 0 },    // Ramp down to 0 users
  ],
};

export default () => {
  http.get('https://quickpizza.grafana.com');
  sleep(1);
};
```

## Custom Metrics

Create custom metrics using Counter, Gauge, Rate, and Trend types to track application-specific measurements.

```javascript
import http from 'k6/http';
import { Trend, Rate, Counter, Gauge } from 'k6/metrics';
import { sleep } from 'k6';

export const TrendRTT = new Trend('RTT');
export const RateContentOK = new Rate('ContentOK');
export const GaugeContentSize = new Gauge('ContentSize');
export const CounterErrors = new Counter('Errors');

export const options = {
  thresholds: {
    Errors: ['count<100'],
    ContentSize: ['value<4000'],
    ContentOK: ['rate>0.95'],
    RTT: ['p(99)<300', 'p(70)<250', 'avg<200', 'med<150', 'min<100'],
  },
};

export default function () {
  const res = http.get('https://quickpizza.grafana.com/api/json?name=Bert');
  const contentOK = res.json('name') === 'Bert';

  TrendRTT.add(res.timings.duration);
  RateContentOK.add(contentOK);
  GaugeContentSize.add(res.body.length);
  CounterErrors.add(!contentOK);

  sleep(1);
}
```

## Browser Module

The browser module provides Playwright-inspired APIs for browser-based performance testing, collecting frontend metrics alongside protocol-level tests.

```javascript
import { browser } from 'k6/browser';

export const options = {
  scenarios: {
    browser: {
      executor: 'shared-iterations',
      options: {
        browser: {
          type: 'chromium',
        },
      },
    },
  },
  thresholds: {
    checks: ['rate==1.0'],
  },
};

export default async function () {
  const page = await browser.newPage();

  try {
    await page.goto('https://test.k6.io/');
    await page.screenshot({ path: 'screenshot.png' });
  } finally {
    await page.close();
  }
}
```

## WebSocket Testing

Test WebSocket connections with the k6/websockets module, supporting multiple concurrent connections per VU.

```javascript
import { randomString, randomIntBetween } from 'https://jslib.k6.io/k6-utils/1.1.0/index.js';
import { WebSocket } from 'k6/websockets';

const sessionDuration = randomIntBetween(1000, 3000);

export default function () {
  for (let i = 0; i < 4; i++) {
    startWSWorker(i);
  }
}

function startWSWorker(id) {
  const ws = new WebSocket(`wss://quickpizza.grafana.com/ws`);
  ws.binaryType = 'arraybuffer';

  ws.addEventListener('open', () => {
    ws.send(JSON.stringify({ event: 'SET_NAME', new_name: `VU ${__VU}:${id}` }));

    ws.addEventListener('message', (e) => {
      const msg = JSON.parse(e.data);
      if (msg.event === 'CHAT_MSG') {
        console.log(`VU ${__VU}:${id} received: ${msg.user} says: ${msg.message}`);
      }
    });

    const intervalId = setInterval(() => {
      ws.send(JSON.stringify({ event: 'SAY', message: `I'm saying ${randomString(5)}` }));
    }, randomIntBetween(2000, 8000));

    setTimeout(function () {
      clearInterval(intervalId);
      ws.send(JSON.stringify({ event: 'LEAVE' }));
    }, sessionDuration);

    setTimeout(function () {
      ws.close();
    }, sessionDuration + 3000);
  });
}
```

## gRPC Testing

Test gRPC services using the k6/net/grpc module with protocol buffer definitions.

```javascript
import grpc from 'k6/net/grpc';
import { check, sleep } from 'k6';

const client = new grpc.Client();
client.load(null, 'quickpizza.proto');

export default () => {
  client.connect('grpc-quickpizza.grafana.com:443', {
    // plaintext: false
  });

  const data = { ingredients: ['Cheese'], dough: 'Thick' };
  const response = client.invoke('quickpizza.GRPC/RatePizza', data);

  check(response, {
    'status is OK': (r) => r && r.status === grpc.StatusOK,
  });

  console.log(JSON.stringify(response.message));

  client.close();
  sleep(1);
};
```

## Response Object

The Response object returned by HTTP methods contains body content, headers, status codes, cookies, and detailed timing measurements.

```javascript
import { check } from 'k6';
import http from 'k6/http';

export default function () {
  const res = http.get('https://k6.io');

  // Access response properties
  console.log(`Status: ${res.status}`);
  console.log(`Status text: ${res.status_text}`);
  console.log(`Protocol: ${res.proto}`);
  console.log(`URL: ${res.url}`);

  // Access timing information
  console.log(`Blocked: ${res.timings.blocked}ms`);
  console.log(`Connecting: ${res.timings.connecting}ms`);
  console.log(`TLS handshaking: ${res.timings.tls_handshaking}ms`);
  console.log(`Sending: ${res.timings.sending}ms`);
  console.log(`Waiting: ${res.timings.waiting}ms`);
  console.log(`Receiving: ${res.timings.receiving}ms`);
  console.log(`Duration: ${res.timings.duration}ms`);

  // Parse response body
  // const jsonData = res.json();
  // const htmlSelection = res.html().find('h1');

  // Access headers
  for (const header in res.headers) {
    console.log(`${header}: ${res.headers[header]}`);
  }

  check(res, {
    'status is 200': (r) => r.status === 200,
  });
}
```

## Running k6 Tests

Execute k6 tests from the command line with various options for controlling test behavior.

```bash
# Run a basic test
k6 run script.js

# Run with specific VUs and duration
k6 run --vus 10 --duration 30s script.js

# Run with iterations
k6 run --iterations 100 script.js

# Output results to JSON
k6 run --out json=results.json script.js

# Output results to CSV
k6 run --out csv=results.csv script.js

# Run with environment variables
k6 run -e MY_VAR=value script.js

# Run in Docker
docker run --rm -i grafana/k6 run - <script.js

# Run browser tests in Docker
docker run --rm -i grafana/k6:master-with-browser run - <script.js
```

## Summary

Grafana k6 is a comprehensive load testing tool that excels in performance testing scenarios ranging from simple API tests to complex browser-based performance measurements. Its JavaScript-based scripting approach makes it accessible to developers while providing powerful features like custom metrics, thresholds, scenarios, and extensive protocol support. The tool integrates seamlessly with CI/CD pipelines through its threshold-based pass/fail criteria and supports real-time metric streaming to various backends including Grafana Cloud, InfluxDB, Prometheus, and many others.

Common use cases include load testing REST APIs and microservices, browser performance testing for web applications, synthetic monitoring for production systems, chaos engineering when combined with extensions, and integration testing in CI/CD pipelines. k6's scenario-based configuration allows modeling complex traffic patterns with multiple executor types (constant VUs, ramping VUs, constant arrival rate, ramping arrival rate), while its extension ecosystem enables testing of additional protocols like Kafka, Redis, and SQL databases beyond the built-in HTTP, WebSocket, and gRPC support.
